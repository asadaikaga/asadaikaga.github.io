Vimwiki workflow v.s. vim workflow

For a typical vim workflow: open a file, edit the file, close the file

For a vimwiki workflow: open the main wikipage, create a page and edit, back to the main wiki page, create another page (the workflow is continuous, the file tree is naturally revealed in the main wikipage)

We use vimwiki for

  1. a main page for organizing notes (notes classified by folders)
  2. fast create static html files from wiki file
