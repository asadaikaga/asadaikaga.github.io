How to use uv tools for virtual python environment

  • 安装 uv 
    curl -LsSf https://astral.sh/uv/install.sh | sh
  • 创建项目并初始化环境 
    uv init myproject
cd myproject
uv venv

uv init myproject 这行代码比较类似于 git init, 也可以进入myproject文件夹之后直接运行 uv init

还有一个非常邪修的方法。venv的启动文件已经放在.venv/bin 中了，有非常多个activate文件。只需要运行 source activate 就可以进入venv环境了。 

  • source .venv/bin/activate
  • install 
    uv pip install numpy scipy matplotlib

还有一个非常有趣的地方是，在自动创建的 pyproject.toml 中，有一行关于dependencies的代码 

[project]
name = "cond"
version = "0.1.0"
description = "Add your description here"
readme = "README.md"
requires-python = ">=3.13"
dependencies = []
