How to use uv tools for virtual python environment

  • 安装 uv 
    curl -LsSf https://astral.sh/uv/install.sh | sh
  • 创建项目并初始化环境 
    uv init myproject
cd myproject
uv venv

uv init myproject 这行代码比较类似于 git init, 也可以进入myproject文件夹之后直接运行 uv init 

  • source .venv/bin/activate
  • install 
    uv pip install numpy scipy matplotlib
